# Internal Linking Planner

## Procedure

1. Read the supplied page inventory, titles, summaries, and URLs.
2. Group related pages by topic only where the supplied content supports it.
3. Propose links with source page, target page, descriptive anchor, and reader benefit.
4. Identify orphan-like pages only if the inventory is stated to be complete.
5. Flag URLs that cannot be checked from the supplied data.

## Constraints

- Do not claim to check a live website or validate a URL.
- Do not invent page content or force links that do not help the reader.
- Do not use repetitive exact-match anchors.
- Ask the user to verify URL status and destination before publication.

## Output

Provide a reviewable link table and a short list of site-structure questions.

Installation guide

  1. Install the skill folder in a compatible runtime or use SKILL.md manually.
  2. Supply a current page inventory.
  3. Review proposed links and anchors before implementation.

Examples

  • Provide a small page inventory and ask for source page, target page, anchor, and rationale.
