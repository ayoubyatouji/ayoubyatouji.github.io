Installation guide

  1. Import the JSON into a test n8n instance.
  2. Confirm the sample property URL and date range are placeholders.
  3. Configure OAuth using n8n's credential manager only if you choose to extend it.

Examples

  • Inspect the dateRange and propertyUrl fields produced by the manual workflow.

Inputs and outputs

Inputs

  • A manual trigger with placeholder propertyUrl and YYYY-MM-DD values.

Outputs

  • A report-request object only; it does not connect to Google or retrieve data.
