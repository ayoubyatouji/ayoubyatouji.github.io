# SEO Content Optimization

## Procedure

1. Identify the intended reader, question, business goal, and content format.
2. Review the supplied title, headings, copy, and approved sources.
3. Check whether the content answers its purpose clearly and whether important claims are supported.
4. Suggest useful structural changes, examples, and internal links only when relevant destinations are supplied.
5. Preserve meaning, author voice, and first-hand expertise.

## Constraints

- Do not add facts, experience, quotations, or citations that were not supplied.
- Do not repeat keywords unnaturally or recommend duplicate pages for minor query variants.
- Mark facts that need verification.
- Do not publish or edit a live site.

## Output

Return prioritized recommendations with passage-level evidence, followed by a short fact-check and editorial checklist.

Installation guide

  1. Keep the folder name and SKILL.md together.
  2. Use with a compatible SKILL.md runtime or as a manual Markdown checklist.
  3. Provide approved sources and an editorial brief.

Examples

  • Review an existing draft and return evidence-based improvements with unchanged factual claims.
