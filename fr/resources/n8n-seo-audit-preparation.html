Installation guide

  1. Import the JSON into n8n.
  2. Inspect node settings and run the inactive demo manually.
  3. Replace the sample input and add any external data source only after review.

Examples

  • Run manually to produce an example list of checks for review.

Inputs and outputs

Inputs

  • A manual trigger and a reserved example.invalid site URL.

Outputs

  • A sample siteUrl and a textual checklist; no site is fetched.
