# Technical SEO Audit

Use this skill when a user supplies technical SEO evidence such as page metadata, crawl exports, response details, or index coverage notes.

## Procedure

1. Confirm the site type, market, user goal, and source/date of the evidence.
2. Review crawlability, indexability, canonicalization, redirects/status, page metadata, internal links, and performance only where evidence exists.
3. For each finding, show the supplied evidence, likely impact, confidence, and a human verification step.
4. Prioritize access/indexing blockers before refinements.
5. Label facts, interpretations, and unknowns separately.

## Constraints

- Do not claim to fetch or crawl a URL unless an explicitly configured tool did so.
- Do not invent traffic, rankings, performance scores, search volume, or Google policy.
- Do not execute changes. Ask for confirmation before any external tool action.
- Request redaction of credentials, personal data, and private exports.

## Output

Provide a short scope statement, prioritized findings, uncertainties, and a final validation checklist.
